# efatura-earsiv-eirsaliye-rehberi
e-Fatura, e-Arsiv ve e-Irsaliye sureclerinin yazilim tarafi rehberi: belge tipi karar agaci, alici mukellefiyet kontrolu, TEMEL/TICARI senaryo farki, iptal-itiraz-iade ayrimi, siparis akisindaki 10 durak ve 20 maddelik degerlendirme kontrol listesi. Egitici, markdown, kod yok.
